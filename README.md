# MindGrind

A 2D top-down strategy and cognitive puzzle game built for PC.

## Overview

**MindGrind** is a single-player cognitive challenge game where players guide a character through a mysterious simulation-like environment. Progress is locked behind gates that can only be opened by completing mini-games designed to test different aspects of human cognition.

As players advance, they face increasing difficulty, tighter time pressure, and more complex mechanics. The game is designed to be mentally stimulating, competitive, and rewarding, with a strong focus on replayability and performance improvement.

## Game Objective

The main objective of **MindGrind** is to evaluate and challenge the player’s:

- Strategic thinking
- Memory
- Reflexes
- Reasoning
- Perception
- Attention

Players complete mini-games, unlock gates, and progress through levels while improving their cognitive performance scores.

## Core Gameplay

- Top-down character movement using keyboard controls
- Interaction with gates to trigger mini-games
- Completing mini-games to unlock progression
- Increasing level difficulty over time
- Performance tracking across multiple cognitive categories

## Features

- Multiple cognition-based mini-games
- Story-driven level progression
- Performance tracking and analysis
- Replayability through score improvement
- Minimalistic and accessible UI

## Genre

- Single-player
- 2D Top-Down
- Cognitive Puzzle
- Strategy

## Target Audience

**MindGrind** is designed for teenagers and young adults aged **13–30** who enjoy:

- Puzzle-solving
- Strategy games
- Reaction-based gameplay
- Brain-training experiences
- Competitive score-based progression systems

## Platform

- **PC**

## Presentation Goals

### Text

The game uses concise and direct dialogue with a slightly futuristic and experimental tone. Instructions and narrative elements are kept simple to maintain gameplay flow and clarity during high-pressure moments.

### Visual Style

- Minimalist 2D presentation
- Distinct colors for interactable objects and gameplay elements
- Different level themes and color palettes
- Clean interface designed to reduce distraction

### Audio

- Fast-paced electronic and ambient background music
- Responsive sound effects for success, failure, timers, and interactions
- Audio cues integrated into certain mini-games
